About

We're a design studio in Nairobi. We build websites, and we care as much about how they run as how they look. In practice that means pages that load fast on an ordinary phone, code someone else can pick up later, and the search basics handled properly the first time round.

Strategy

How we approach every project?

01

Performance First

Speed gets decided early, so we start there. Small pages, images sized properly, nothing heavy running for no reason. The test is never your laptop on office wifi. It's a mid-range phone on a bad afternoon.

02

Clean & Scalable Code

Someone will open this project a year from now, and it might not be us. So we keep it readable. Adding a page later should take an afternoon. On plenty of sites it takes a rebuild, and that was a choice somebody made early on.

03

Modern UI & UX

Layouts people can read without working at it. We settle the spacing, the movement and how it behaves on a phone at the same time rather than one after the other, because doing it in that order is where most sites come apart.

04

SEO & Best Practices

Proper markup, real page titles, metadata that says something. We do it while we build. Bolting it on six months later, once the traffic hasn't turned up, costs more and works less well.

05

Reliable Delivery

You will know what we are building, what it costs and when it goes live. If something slips you hear it from us first, not when you notice the date has quietly moved.
